# Capital Decision Lab

Capital Decision Lab is a private, local-first comparison tool for uncertain choices involving capital, time, opportunity cost, and exposure.

The first release boundary is deterministic and offline. It accepts explicit user inputs, records assumptions, produces calculated results and modeled ranges, and preserves human control over decisions and authorization.

Outputs are comparison only, not financial advice. No live data, account connection, transaction execution, cloud synchronization, or external service is included.
