# Confirmation Gates

Screenshot and low-confidence extraction results are not eligible for analysis
until a human confirmation is hash-bound to the extraction. A correction is
treated as human-confirmed only after the corrected document and extraction
metadata are updated.

The workflow stops in this order when required inputs are absent:

1. portfolio snapshot
2. confirmed bull/base/bear thesis
3. margin inputs
4. extraction confirmation

Pending or rejected belief proposals cannot alter calculations. Contradictory
evidence is preserved in synthesis and can produce a watch result with a prompt
for the user to select the decision priority. Every recommendation still
requires a separate human authorization before any record operation.
