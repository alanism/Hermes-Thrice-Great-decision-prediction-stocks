# Source Extraction Adapters

Adapters normalize host results for Polymarket, X/Twitter, Reddit, portfolio tables, broker margin screens, and manual notes.

Polymarket produces an event-market snapshot and classifies likely domains. X/Twitter and Reddit produce evidence batches. Portfolio tables produce portfolio snapshots. Broker margin screens preserve account equity, borrowing, requirements, thresholds, buying power, and cash as extracted fields. Manual notes preserve user text without adding facts.

Source-specific extraction is mandatory before analysis. Generic HTTP or browser content alone is not belief-update eligible.
