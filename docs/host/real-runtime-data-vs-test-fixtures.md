# Real Runtime Data and Test Fixtures

Synthetic fixtures exist only for automated tests and demos. They are not production evidence.

At runtime, Hermes supplies real user-provided or connector-retrieved portfolio records, screenshots, broker exports, URLs, posts, threads, local files, pasted evidence, and notes. Every runtime source retains provenance and stays in local user storage outside Git.

The repository must never contain real holdings, account screens, credentials, session material, or private runtime extraction output.
