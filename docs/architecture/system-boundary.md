# System boundary

Capital Decision Lab is a private, local, deterministic comparison profile. It accepts explicit files, validates contained paths, separates input classes, and produces machine-readable results whose semantic values are provenance-labeled evidence atoms.

The CLI MVP includes deterministic calculations, seeded modeled ranges, unranked comparisons, hash-bound authorization validation, and atomic local ledger append. It contains no external adapter, network capability, transaction execution, or model-created financial facts.
